## Keyword search

`⌘K` (or `Ctrl+K`) opens search from anywhere. It is a Lucene index over every
note, returning ranked hits with the matching phrase highlighted in context.

The overlay searches more than notes: categories, collections and even settings
pages are matched, so "retention" takes you to the Trash setting rather than
making you remember which tab it lives on.

If the index is rebuilding or the server is unreachable, search does not simply
stop working — it falls back to matching over the notes already cached in your
browser and labels the results as partial. Cruder, but never a dead end.
