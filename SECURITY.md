# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems.
Report it privately: https://github.com/lyfie-org/papyra/security/advisories/new

Include what you found, how to reproduce it, and which version you were running.
I'll reply as soon as I can, and credit you in the release notes if you'd like.

## Supported versions

Only the latest release gets security fixes. Papyra is self-hosted, so please
update promptly: Docker users can pull the newest image.

## Scope

In scope: the Papyra API, web app, live-editing engine and the official Docker image.
Out of scope: problems that need an already-compromised server or admin account,
and vulnerabilities in your reverse proxy or hosting setup.
